# Vidushi Singh — Personal Portfolio

This is Vidushi's customized version of **The H Portfolio Template** by Ameer Hamza.

## Open the portfolio locally

1. Extract the ZIP file.
2. Open the extracted `Vidushi-Singh-Portfolio` folder.
3. Double-click `index.html` to open the portfolio in your browser.
4. Use the opening screen to enter the portfolio. Try the navigation, project cards, intro dialog and contact links.

The site is a static HTML/CSS/JavaScript website. It does not require Node.js, a database, an API key or a build step.

## Customize your content

- Main content: `portfolio.config.js`
- Main page: `index.html`
- Styling and responsive layout: `styles.css`
- Animations and interactions: `app.js`
- Portrait: `assets/vidushi-singh.jpg`

You can also open `customize.html` in a browser and use the built-in no-code customizer. Export the generated `portfolio.config.js`, then replace the existing file in this folder.

## Publish with GitHub Pages

1. Create a new public repository in your GitHub account.
2. Upload the **contents** of this folder (so `index.html` is at the repository root).
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Wait for GitHub Pages to finish deploying. Use the URL displayed in Settings → Pages and test it.

The repository URL is where the source files live. The GitHub Pages URL is the public website. They are different URLs. Do not assume deployment is live until GitHub Pages reports success and the website opens.
