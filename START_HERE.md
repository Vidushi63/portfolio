# Start here — Vidushi Singh Portfolio

1. Extract this ZIP.
2. Open `index.html` in Chrome, Edge or Firefox.
3. The website is static; no installation or build command is needed.
4. To change your content, edit `portfolio.config.js` or open `customize.html` for the built-in no-code editor.
5. Keep `assets/vidushi-singh.jpg` in the `assets` folder. Do not rename it unless you also update `portfolio.config.js`.
6. Keep the original `LICENSE` file.

For publishing, see `README.md`.
